# App-owned prompt bundle

The versioned files in [v1](v1/) are the default POC prompt assets, shipped with the worker image. [manifest.json](manifest.json) identifies the mandatory policy and six replaceable role prompts, including a dedicated history_import role. Discussion customization affects only investigation; history import has separate prompt, model and timeout settings.

Assembly has three layers: mandatory policy, the app's default role prompt or project replacement, and project additions. Configuration selects a known bundle version and may supply role-specific `replacement` and `additions`; it cannot supply a replacement for the mandatory policy. Mandatory lenses, built-in quality checks and custom rules are supplied in the stage input. Custom rules are additive to built-ins. Mandatory instructions have precedence over all customizable text, and application validators enforce coverage, severity, schema and workflow requirements independently.

Persist the actual assembled text, its SHA-256, bundle version, mandatory-policy reference, default-role reference, optional replacement reference and ordered addition references. The assembly delimiter is two newlines between trimmed components, with one final newline; this makes example prompt hashes reproducible. Stage inputs and tool permissions are recorded separately. A different prompt component/version or assembly policy invalidates affected checkpoints. Pin the bundle in the request and reject unknown versions rather than silently using a newer default.

These prompt assets establish a reviewable baseline. They do not prove investigation quality or runtime compatibility; representative POC evaluations remain necessary. Conditional checks that cannot be represented in the simple agent output schema are listed in [validation rules](../docs/schema-validation.md).

Technical discussion uses two agents: the discussion role investigates, and the independent verification role assesses the proposal and writes final replies. Review mode likewise ends with independent verification and final replies after the reviewers; there is no subsequent reconciliation agent. Code applies lifecycle changes in both modes. Command-only discussion skips both agents, and an empty review candidate pool with no required technical replies skips verification. Mandatory policy also protects per-finding closure selection and independent relevant-change verification from project prompt replacement.
